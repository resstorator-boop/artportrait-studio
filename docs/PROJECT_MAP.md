# NUMERO — Карта проекта

> **Назначение документа.** Канонический план проекта. К нему возвращаемся при любых откатах и сомнениях «куда мы идём». Обновляется по мере смены вектора — старые версии остаются в истории Space.
>
> **Версия:** v0.3 (16 мая 2026)
> **Владелец:** Денис Викторович
> **Текущий стек:** Next.js 14 + TS, Clerk, Drizzle/Neon Postgres, Robokassa, Inngest, Cloudflare R2, Vercel, Unisender Go

---

## 0. История сдвигов

**v0.1 (исходно):** AI-платформа арт-фотосессий в стиле культовых фотографов (Newton, Coppola, Tarantino).

**v0.2:** Сдвиг в личный брендинг для инфлюенсеров — отложено, не подтвердилось гипотезами.

**v0.3 (текущее, NUMERO):** Возврат к арт-направлению с новой механикой — **еженедельные премьеры авторов**. Один новый автор/режиссёр каждую неделю — куратор сезонной коллекции. Без подписки, три разовых пака (100/700/2900 ₽). ЦА — эстет 25–45 (куратор/коллекционер/даритель), а не инфлюенсер. Маркетплейс промптов отложен в Phase 2 («чулан идей»).

## 3. Зависимости

```
Идея v3.6 ──► PRD v2 ──► Архитектура ──► Лендинг v2 ──► Воронка ──► Трафик
                              │              │             │
                              └──────────────┴──► Тексты приманки, пробника, писем
                                                  (требуют готового оффера)
```

**Практический смысл:**
- Лендинг без оффера по 5 рычагам = переписывать тексты заново.
- Воронка без работающего лендинга = тестировать нечего.
- Трафик без воронки = терять деньги на холодной аудитории.

## 4. Ближайшие 5 шагов

1. **Оффер по 5 рычагам** (слой 2) — собрать формулировку, на которую эстет 25–45 скажет «Ммм, расскажи подробнее».
2. **Обкатка оффера** на 5–10 живых людях (Анна/Сергей/Мария-типажи).
3. **Лендинг v2** (слой 4.2) на основе утверждённого оффера — на Tilda для скорости, потом миграция на Next.js.
4. **Приманка** (слой 5.1) — собрать квиз «твой автор» как подписную страницу.
5. **Параллельно стартуем разработку** по архитектуре (`drizzle-kit push` + структура папок) — слой 4 и 5 будут готовы быстрее, если backend уже на dev.

## 5. Правила работы с этой картой

- **Один источник правды.** Если в чате/коде что-то противоречит этой карте — либо обновляем карту, либо возвращаем код к карте. Не наоборот молча.
- **Версионирование.** При большом сдвиге поднимаем версию (v0.2 → v0.3) и пишем краткое «что изменилось» в разделе 0.
- **Откат = вернуться к ближайшему ✅.** Не переписываем всё с нуля.
- **Артефакты ссылаем на файлы Space.** В колонке «Артефакт» — имя файла или ссылка на сессию.
